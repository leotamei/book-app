About Book Explorer

Welcome to Book Explorer! This Single Page Application (SPA) was built for Module 2 of the Software Development program.

The goal of this project is to create an interactive web application that fetches book data in real time, allows users to manage a reading list, and submits community reviews to a remote server.

Key Features:
  • Live Search: Fetches real book data using the public Open Library Search API (GET Request).
  • Favorites List: Save books into a personal reading list without reloading the page.
  • Review System: Submit user reviews using JSONPlaceholder API (POST Request).
  • Error Handling: Displays dynamic Bootstrap alert messages if network or API calls fail.
